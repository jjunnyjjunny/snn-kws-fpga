# SPEC_snn_core — M3k3 SNN 코어 연산 사양 (골든 `snn/golden/snn_int_ref.py` 대응)

동결 사양: 스파이킹 1D TCN, K=3 탭, dilation 1/2/4/8, 64ch × 4층, 출력 12(또는 10) 클래스, 가중치 8비트,
LIF k=3 감산 리셋, 뉴런별 정수 θ·b, 막전위 16비트 포화, 입력층 in_shift=6(`snn/rom/m3k3_params.json`), 출력 적분기 24비트, 판정 = 시간 합 argmax.
RTL은 `.mem`만 바꾸면 그대로 동작해야 하므로 구조·비트폭은 파라미터로 두되 아래 값으로 고정한다.

## 1. 파라미터와 메모리 (`snn/rom/README.md`, `m3k3_params.json`)

| 기호 | 값 | 비고 |

| D_l | 1, 2, 4, 8 | 층 l=1..4 dilation |
| N_PRE_l | 120, 192, 192, 192 | 층 l 입력 벡터 길이 = K × (N_IN 또는 N_HID) |
| IN_SHIFT | 6 | 입력층 누적기 우시프트 |
| LEAK_K | 3 | 모든 층·출력 누설 시프트 |

## 2. 프레임 t의 연산 순서 (골든 `run_int`, 줄 41–67)

프레임마다 다음을 **층 1 → 2 → 3 → 4 → 출력** 순서로, 층 안에서는 **(a) 전류 누적 → (b) 뉴런 갱신** 순서로 수행한다. 층 l+1은 같은 프레임 t에서 방금 계산된 층 l의 스파이크를 탭 0으로 쓴다(줄 65 `inp = st['s']`).

### 2.1 입력 벡터 구성 (줄 45–47)
- 층 l의 입력 히스토리 `hist_l`에 프레임 t의 입력(층1: 특징 x[t] 40개, 층 l≥2: 층 l−1의 스파이크 s_{l−1}[t] 64개)을 추가(줄 45).
- 탭 j = 0..K−1 은 프레임 **t − j·D_l** 의 입력을 쓴다. t − j·D_l < 0 이면 **0 벡터**(줄 46). 즉 리셋 직후 과거 히스토리는 전부 0.
- 입력 벡터 `inp_vec = concat(tap0, tap1, tap2)` → pre 인덱스 = **j × N_in + ch** (줄 47). 가중치 ROM 행 번호 = pre.
- 필요한 히스토리 깊이: 층 l 입력은 최근 D_l·(K−1)+1 프레임 = 3, 5, 9, 17 프레임.

### 2.2 전류 누적 (줄 50–53)
- `I[post] = Σ_pre inp_vec[pre] × W_l[post][pre]` (줄 50). numpy 가중치 배열은 [post][pre]이고 `.mem` 주소는 pre×N_POST+post 로 저장돼 있다(README).
  - 층1: x는 0..255(8비트 unsigned), W는 −128..127 → 곱 16비트 부호, 120항 합 |I| ≤ 255×127×120 = 3,886,200 → **24비트 부호 누적기**(23비트면 충분, 여유 1비트).
  - 층2~4: inp_vec는 0/1 → **곱셈 없음**, 활성(1) pre의 W 행만 가산. 192항 → |I| ≤ 24,384(16비트). 같은 24비트 누적기 사용.
  - 출력층: 64 pre × 12 post, |I| ≤ 8,128.
  - **0 건너뛰기**: inp_vec[pre]=0 인 행은 곱·가산·ROM 읽기 모두 생략(결과 동일). 층1은 x=0 행, 층2~4·출력층은 s=0 행.
- 층1만 `I = I >> IN_SHIFT` (줄 51–52): numpy int64 `>>` = **산술 시프트(음수 floor)**. 24비트 부호 값의 `>>> 6`.
- `I = I + b[post]` (줄 53): 시프트 **후** 바이어스 가산. b는 16비트 부호. 결과 I는 층1 최대 |60,722 + 32,768| → 18비트 부호; 층2~4 17비트. RTL은 24비트로 통일.

### 2.3 LIF 갱신 (`lif_step`, 줄 17–21, 호출 줄 62)
뉴런 post마다, 이전 프레임 끝의 막전위 v(16비트 부호)에 대해 **정확히 이 순서**:
1. `leak = v >>> LEAK_K` (산술 시프트, 음수는 −∞ 방향 floor: 예 −5>>>3 = −1)
2. `tmp = v − leak + I` (줄 18 안쪽; 26비트 부호로 계산)
3. `v' = sat16(tmp)` : tmp > 32767 → 32767, tmp < −32768 → −32768 (줄 18 `sat`, 줄 12–14). **포화는 전류 가산 후, θ 비교 전**.
4. `s = (v' >= θ)` (줄 19, 부호 비교: v' 16비트 부호 vs θ unsigned 16비트 → θ ≤ 65535 지만 실제 ≤ 285; RTL은 17비트 부호로 비교)
5. `v'' = v' − s·θ` (줄 20, 감산 리셋; **포화 없음** — v' ≥ θ ≥ 0 이므로 범위 안)
6. 저장: v ← v'' (다음 프레임용), 스파이크 s → 히스토리 `hist_{l+1}` 프레임 t 슬롯, 테스트 벡터 `<layer>_v.hex`는 **리셋 후 v''**, `<layer>_s.hex`는 s (`dump_vectors.py`).

### 2.4 출력 적분기 (줄 66–67)
- `I_o[c] = Σ_pre s4[t][pre] × W_out[c][pre] + b_out[c]`
- `vo[c] = sat24(vo[c] − (vo[c] >>> 3) + I_o[c])` — 포화 24비트, 스파이크 없음, 리셋 없음.
- `vout[t] = vo` 기록(테스트 벡터 `out_v.hex`).

### 2.5 판정 (줄 68)
- `sum[c] = Σ_{t=0}^{T−1} vout[t][c]` (T=98, |sum| ≤ 98×2^23 < 2^30 → **32비트 부호**). 클립 평가는 clip_start 이후 전체 합.
- `pred = argmax_c sum[c]` — numpy `argmax`는 **동점이면 가장 낮은 인덱스**. RTL: c=0부터 순차 스캔, `sum[c] > best`(엄격) 일 때만 갱신.
- 스트리밍 확장(B-4에서 규칙 확정, RTL은 파라미터로만 준비): 최근 W 프레임 창 합(WIN_SUM, 기본 98 = 클립 길이 → 클립 모드와 동일), 마진 MARGIN(기본 0), 연속 N_CONSEC(기본 1), 불응기 REFRACT(기본 0), silence/unknown(인덱스 ≥ N_KEYWORD=10) 비검출.

### 2.6 초기 상태 (줄 31–38)
`clip_start`(또는 rst) 시: 모든 v=0, vo=0, 모든 히스토리(특징 3프레임, 스파이크 5/9/17/1프레임)=0, sum=0, 창 링=0. 스트리밍 모드에서는 clip_start 없이 프레임을 계속 넣으며 상태를 유지한다(골든 = 이어붙인 시퀀스에 `run_int` 1회).

## 4. RTL 프레임 처리 시퀀스 (snn_ctrl)
```
IDLE ──feat_valid(첫 특징)──► 히스토리 1프레임 시프트(fh[2]←fh[1]←fh[0]; sh_l[i]←sh_l[i−1]) ; LOAD
LOAD : 40개 특징을 fh[0][idx]에 기록, feat_last ──► L1
층 l=1..4, 출력층(OUT) 각각:
  CLR   : acc[*] ← 0
  ROWCHK: row r=(j,ch) 활성 읽기 a (층1: fh[j][ch]; 층l: sh_{l−1}[j·D_l][ch]; OUT: sh4[0][ch]);
          a==0 → 다음 행(1사이클) ; a≠0 → ROWRUN
  ROWRUN: post=0..N_POST−1 : ROM 주소 r·N_POST+post 읽기 → prod=(층1 ? a×w : w) → acc[post]+=prod (1/사이클, 2단 파이프)
  DRAIN : 파이프 비움(2사이클)
  UPD   : post=0..N−1 : I=(층1 ? acc>>>6 : acc)+b ; LIF(2.3) 또는 출력 적분(2.4) ; v_mem/sh_l[0]/vo 기록 (1/사이클)
DECIDE : 창 합 갱신(12사이클, 링 BRAM 읽기 파이프) → argmax 스캔(12사이클) → frame_done 펄스 → IDLE(busy=0)
```
