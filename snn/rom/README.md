# snn/rom — $readmemh ROM images for the KWS front-end / SNN

All files: one hex word per line, line index = address (after 2 comment lines starting with `//`).
Signed values are two's complement in the stated width. Generated by `snn/frontend/export_roms.py`
(front-end) and `snn/golden/export_snn_mem.py` (SNN weights).

## Front-end ROMs

| file | width (bits) | depth | address / content rule |
|---|---|---|---|
| `hann_w480.mem` | 16 | 480 | addr n = sample index within frame; w[n] = 0.5-0.5cos(2*pi*n/WIN) * 32768, max 32767 |
| `hann_w400.mem` | 16 | 400 | addr n = sample index within frame; w[n] = 0.5-0.5cos(2*pi*n/WIN) * 32768, max 32767 |
| `twiddle_re.mem` | 16 | 256 | addr k = 0..255 ; W_512^k real = cos(2*pi*k/512) * 32768 (32767 max) |
| `twiddle_im.mem` | 16 | 256 | addr k = 0..255 ; W_512^k imag = -sin(2*pi*k/512) * 32768 |
| `mel40_table.mem` | 26 | 40 | addr m = mel band; bits[25:17]=start_bin(0..256) bits[16:10]=length bits[9:0]=offset into weights ROM |
| `mel40_weights.mem` | 8 | 488 | addr = table.offset + j, j=0..length-1 ; weight for bin start_bin+j (0..255 = 0..1.0) |
| `mel32_table.mem` | 26 | 32 | addr m = mel band; bits[25:17]=start_bin(0..256) bits[16:10]=length bits[9:0]=offset into weights ROM |
| `mel32_weights.mem` | 8 | 484 | addr = table.offset + j, j=0..length-1 ; weight for bin start_bin+j (0..255 = 0..1.0) |
| `log2_lut.mem` | 5 | 32 | addr i = 5 bits right below the leading one; log2q = (lead_pos<<4) + LUT[i] |
| `decim_coef.mem` | 16 | 67 | addr k = tap index; y[n] = (sum_k h[k] x[3n-k] + 2^14) >> 15 ; polyphase E_p[j]=h[3j+p] |

## Fixed-point conventions (fe_config.py)
- PCM in: 24-bit signed. Input scaling: `x_db = sat18((pcm + 2^5) >> 6)`.
- Framing: hop 160, win 480, T = 98 frames per 16000 samples, frame t = x[160t : 160t+WIN], zero-pad to 512.
- Window: `xw = sat18((x_db * hann + 2^14) >> 15)`.
- FFT: radix-2 DIT, bit-reversed input, 9 stages, twiddle index for stage s (m=2^s): k * (512/m).
  butterfly: `p = b*W` (complex, products 18x16), `a' = sat((a<<15 + p + 2^15) >> 16)`, `b' = sat((a<<15 - p + 2^15) >> 16)`.
  Overall gain 1/512.
- Power: `P[k] = re^2 + im^2`, k = 0..256, unsigned 36 bits, no truncation.
- Mel: `acc[m] = sum_j w[m,j] * P[start_m + j]`, unsigned 50-bit accumulator.
- log2: `lead = position of leading one (0 for acc==0)`, `mant = 5 bits right below lead` (zero-extended if lead<5),
  `log2q = (lead << 4) + LUT[mant]` (10 bits), log2q(0) = 0.
- Feature: `f = clip(log2q - 332, 0, 255)` (8-bit unsigned).

## SNN `m3k3` (M3) — generated by snn/golden/export_snn_mem.py

| file | width (bits) | depth | address / content rule |
|---|---|---|---|
| `m3k3_tcn1_w.mem` | 8 | 7680 | addr = pre*64 + post (pre = input/presynaptic index, post = neuron index) |
| `m3k3_tcn1_b.mem` | 16 | 64 | addr = neuron index; signed constant current added to I every frame |
| `m3k3_tcn1_theta.mem` | 16 | 64 | addr = neuron index; unsigned threshold in membrane units |
| `m3k3_tcn2_w.mem` | 8 | 12288 | addr = pre*64 + post (pre = input/presynaptic index, post = neuron index) |
| `m3k3_tcn2_b.mem` | 16 | 64 | addr = neuron index; signed constant current added to I every frame |
| `m3k3_tcn2_theta.mem` | 16 | 64 | addr = neuron index; unsigned threshold in membrane units |
| `m3k3_tcn3_w.mem` | 8 | 12288 | addr = pre*64 + post (pre = input/presynaptic index, post = neuron index) |
| `m3k3_tcn3_b.mem` | 16 | 64 | addr = neuron index; signed constant current added to I every frame |
| `m3k3_tcn3_theta.mem` | 16 | 64 | addr = neuron index; unsigned threshold in membrane units |
| `m3k3_tcn4_w.mem` | 8 | 12288 | addr = pre*64 + post (pre = input/presynaptic index, post = neuron index) |
| `m3k3_tcn4_b.mem` | 16 | 64 | addr = neuron index; signed constant current added to I every frame |
| `m3k3_tcn4_theta.mem` | 16 | 64 | addr = neuron index; unsigned threshold in membrane units |
| `m3k3_out_w.mem` | 8 | 768 | addr = pre*12 + post (pre = input/presynaptic index, post = neuron index) |
| `m3k3_out_b.mem` | 16 | 12 | addr = neuron index; signed constant current added to I every frame |

Parameters (k = leak shift per layer, in_shift = input-layer accumulator shift, bit widths): `m3k3_params.json`.
Neuron update (per layer, per frame): `v = sat_s16(v - (v >>> k) + I)`; `spike = (v >= theta)`; `if spike: v -= theta`.
Input layer: `I = ((sum_i x[i] * W[i][j]) >>> in_shift) + b[j]` (x = 8-bit feature, arithmetic shift = floor).
Hidden layers: `I[j] = b[j] + sum over spiking pre i of W[i][j]` (no multiply). Output: `vo = sat_s24(vo - (vo >>> k) + I)`;
decision = argmax over classes of sum_t vo[t] (equivalently mean); alt: last step / max over t.
TCN: layer input vector = concat over taps j=0..K-1 of input at frame t - j*dilation (zeros for t<0). 1-bit spike history per layer.
